🚀 Desplegando aplicaciones modernas

Descubre cómo crear y desplegar sitios web estáticos de forma rápida y eficiente. Este proyecto demuestra las mejores prácticas para el desarrollo web moderno usando tecnologías actuales.

Ver características 📖 Guía de despliegue 🎯 Ver demo
⚡

Sin build

Usamos Tailwind por CDN (Red de Entrega de Contenido), así que no necesitas Node ni compilar. Desarrollo instantáneo.

🪶

Ligero y rápido

Solo HTML, CSS y JS vanilla. Perfecto para demos, portafolios, documentación y proyectos académicos.

🌐

Fácil de desplegar

Compatible con GitHub Pages, Netlify Drop, Vercel y cualquier hosting estático. Despliega en segundos.

📚 Guía rápida de despliegue

🐙 GitHub Pages

  1. 1. Sube tu código a un repositorio GitHub
  2. 2. Ve a Settings → Pages
  3. 3. Selecciona la rama main
  4. 4. ¡Tu sitio estará en línea!

🌟 Netlify

  1. 1. Arrastra tu carpeta a netlify.com/drop
  2. 2. Netlify procesará automáticamente
  3. 3. Obtienes una URL única
  4. 4. ¡Listo para compartir!
